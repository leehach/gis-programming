# Overview

## Course Description

Building on previous coursework with Geographic Information Systems (GIS), students will learn computer programming in a GIS environment. Students will design and execute spatial analysis and geovisualization projects using open source geospatial and data science Python packages. Students will learn programming concepts such as variable typing, function definition, conditional evaluation, looping, and object-oriented programming.

Python has rapidly become the *de facto* standard for scientific computing. It is also the scripting language used by two prominent GIS packages, ArcGIS (proprietary) and QGIS (open source). There is also an extensive and growing ecosystem of Python packages for geospatial analysis. The course will introduce fundamental concepts in programming using the textbook *Think Python 3e*, and geospatial data science using the textbook *Introduction to Python for Geographic Data Analysis*. We will also make use of [DataCamp](https://www.datacamp.com/) interactive tutorials to learn Python syntax and reinforce these fundamental concepts.

The first few weeks of the course will feature weekly exercises and quizzes on basic building blocks. The latter part of the course will go further into Python geospatial programming. In this part of the course, students will present tutorials on further topics.

## Assignments in Brief

You will earn points along several **tracks**. Each track is worth up to 100 points. Your must progress along ***ALL*** tracks to be successful in this course. Your final grade is based on the ***lowest*** score earned along any track.

The tracks and points associated with each assignment in the track are as follows:

Attendance
: 0-100 points. Your attendance score is a straight percentage of the class sessions you are present for.

Programming Quizzes (6)
: 54 base score.
: 10 points each for quizzes 1 through 3.
: 3 points each for quizzes 4 through 6.

DataCamp (5)
: 50 base score
: 10 points each course completed fully

Programming Assignments (3)
: 59 base score
: 10 points Assignment 1 - Vector Operations
: 10 points Assignment 2 - Raster Operations
: 20 points Assignment 3 - Analysis Pipelines

Student-Led Tutorial
: 70-100 points. The tutorial is a skills workshop developed and presented by teams of 3-4 students based on topics discussed in class. The tutorial is awarded up to 30 points based on written materials (a workbook) and presentation.

Exercises (8)
: 1/2 bonus point each (4 max) added to the lowest other track.
