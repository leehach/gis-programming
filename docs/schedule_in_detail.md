# Schedule in Detail

The assigned readings for each class meeting are Jupyter notebooks, web pages with embedded code cells. You will get the most out of "reading" these notebooks by opening them in VS Code, reading the explanatory text, and executing the code cells as you read. Instructions for setting up your Python development environment and downloading the notebooks will be provided separately. Readings should be completed *prior to* each class meeting.

In the following list:

* TP3 refers to [*Think Python 3e*](https://allendowney.github.io/ThinkPython/index.html)
* PythonGIS refers to [*Introduction to Python for Geographic Data Analysis*](https://pythongis.org/)
